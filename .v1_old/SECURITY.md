# Security policy

Report vulnerabilities privately through
[GitHub Security Advisories](https://github.com/ravazque/ravazque.github.io/security/advisories/new), never in a
public issue. Include the affected page or endpoint, the steps to reproduce and the impact.

In scope: the web app (`web/`, `core/`), its Docker and Caddy configuration, and the GitHub Pages site (`site/`).
Out of scope: the 42 API and intra themselves, and denial of service through volume.
